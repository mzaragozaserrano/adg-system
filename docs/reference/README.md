|--------|-----|-------------------|

| Obsidian Blue | `#01222E` | Subtítulos (Light) |
| Blanco | `#F6F6F6` | Fondos |
| Platino | `#CECECD` | Fondos / acentos |
| Azul Digital | `#005C7F` | Elementos gráficos |
| Acero Glaciar | `#6A96A6` | Elementos gráficos |
| Negro | `#000000` | Texto de cuerpo |
